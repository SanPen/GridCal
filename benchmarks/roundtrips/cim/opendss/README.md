# OpenDSS CIM Roundtrip Benchmark

This benchmark checks plain CIM interoperability between OpenDSS and VeraGrid on a small set of roundtrip examples ranging from one tiny synthetic feeder to real OpenDSS-exported feeders.

Flow:

`OpenDSS CIM -> VeraGrid import -> VeraGrid power flow -> VeraGrid CIM export -> VeraGrid re-import -> VeraGrid power flow`

Pass condition:

- both VeraGrid power flows converge
- the roundtrip voltage vector matches the first solve within `1e-6`

## Benchmark Files

- `simple_source_load.xml`
  - tiny two-bus source-line-load CIM case copied from the CIM interop test
- `simple_source_load_shunt.xml`
  - tiny two-bus source-line-load-shunt CIM case copied from the CIM interop test patterns
- `ieee13assets.xml`
  - real OpenDSS IEEE13 asset-oriented CIM export, useful as an import/solve case
- `ieee13cdpsm.xml`
  - real OpenDSS IEEE13 CDPSM-oriented CIM export
- `ieee13_cdpsm_roundtrip.py`
  - generic standalone runner for one chosen fixture
- `run_all.py`
  - runs every committed fixture in this folder
- `*_roundtrip_export.xml`
  - generated by the runner, not committed

## Fixture Provenance

`ieee13cdpsm.xml` and `ieee13assets.xml` were generated from the official OpenDSS command-line distribution under `wine`, using the bundled OpenDSS CIM export script.

Upstream OpenDSS inputs used to generate the fixture:

- `opendsscmd.exe` from the official OpenDSSCmd package
- bundled `cim_test.dss`
- bundled `IEEE13_CDPSM.dss`
- bundled `IEEE13_Assets.dss`
- bundled `IEEELineCodes.DSS`
- bundled UUID data files:
  - `IEEE13Nodeckt_Base_UUIDS.dat`
  - `IEEE13NodecktAssets_Base_UUIDS.dat`

The direct OpenDSS command that emitted the fixture was:

```text
redirect cim_test.dss
```

That script produces:

- `ieee13cdpsm.xml`
- `ieee13assets.xml`
- fragment exports such as `ieee13cdpsm_FUN.XML`, `ieee13cdpsm_TOPO.XML`, `ieee13cdpsm_SSH.XML`

For the VeraGrid benchmark:

- `ieee13cdpsm.xml` is the larger real feeder case
- `simple_source_load.xml` is the smallest deterministic sanity-check case
- `simple_source_load_shunt.xml` is the smallest deterministic shunt-preservation case
- `ieee13assets.xml` is kept as an additional real OpenDSS input, but it is not part of `run_all.py` because the current CIM exporter rejects one zero-rate branch in that asset-oriented case

## Local VeraGrid Inputs

To run the roundtrip benchmark inside this repo you only need:

- `benchmarks/roundtrips/cim/opendss/ieee13cdpsm.xml`
- `benchmarks/roundtrips/cim/opendss/ieee13_cdpsm_roundtrip.py`
- the VeraGrid source tree under `src/`

## System Setup

Minimal setup to run the VeraGrid-side benchmark:

- Linux
- `python3`
- the VeraGrid Python dependencies already installed for this repo

Minimal setup to regenerate the OpenDSS fixture from upstream:

- Linux
- `python3`
- `wine`
- official `OpenDSSCmd` Windows package installed in a wine prefix

This benchmark does not require `wine` unless you want to regenerate the source fixture from OpenDSS yourself.

## How To Run

Run one fixture from the repo root:

```bash
python3 benchmarks/roundtrips/cim/opendss/ieee13_cdpsm_roundtrip.py
```

Run one specific fixture:

```bash
python3 benchmarks/roundtrips/cim/opendss/ieee13_cdpsm_roundtrip.py benchmarks/roundtrips/cim/opendss/simple_source_load.xml
python3 benchmarks/roundtrips/cim/opendss/ieee13_cdpsm_roundtrip.py benchmarks/roundtrips/cim/opendss/simple_source_load_shunt.xml
python3 benchmarks/roundtrips/cim/opendss/ieee13_cdpsm_roundtrip.py benchmarks/roundtrips/cim/opendss/ieee13cdpsm.xml
```

Run all committed examples:

```bash
python3 benchmarks/roundtrips/cim/opendss/run_all.py
```

Optional import/solve-only real OpenDSS case:

```bash
python3 benchmarks/roundtrips/cim/opendss/ieee13_cdpsm_roundtrip.py benchmarks/roundtrips/cim/opendss/ieee13assets.xml
```

Today that case is expected to stop at export because one imported branch carries a zero rate and the current plain-CIM exporter refuses to write zero-rate transformer data.

Expected output for each example ends with:

```text
ok
```

## Regression Test

The same fixture is also covered by the CIM test file:

```bash
cd src
python3 -m pytest tests/FileFormats/CIM/test_cim_opendss_interop.py -q
```

## Regenerate The Fixture From OpenDSS

If you want to reproduce `ieee13cdpsm.xml` from OpenDSS instead of using the committed fixture:

1. Install the official OpenDSSCmd Windows package into a wine prefix.
2. Start the OpenDSS prompt from its bundled `test` directory.
3. Run:

```text
redirect cim_test.dss
```

4. Copy the emitted `ieee13cdpsm.xml` into this folder.

The bundled OpenDSS test directory is used on purpose here because it already carries the exact DSS inputs and UUID files expected by `cim_test.dss`.
